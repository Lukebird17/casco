# 条件码是一组标志位的统称

– 条件码由PSTATE寄存器维护– N（Negative）、Z（Zero）、C（Carry）、V（Overflow）

条件码保留之前相关指令的执行状态，这种指令包括：

– 带有s后缀的算术或逻辑运算指令（如subs、adds）

# 比较指令

• cmp：操作数之差；例如 cmp x0, x1  
• cmn：操作数之和；例如 cmn x0, x1  
• tst ：操作数相与；例如 tst x0, x1
