# 数据管理结构重构方案

## 新的目录结构

```
rag-agent/
├── data/                           # 原文件存储
│   ├── default/                    # 默认知识库的原文件
│   │   ├── OS-01.pdf
│   │   ├── OS-02.pdf
│   │   └── notes.txt
│   ├── physics/                    # physics知识库的原文件
│   │   ├── 力学.pdf
│   │   └── 电磁学.pdf
│   └── programming/                # programming知识库的原文件
│       └── python.pdf
│
├── vector_db/                      # 向量数据库存储
│   ├── default/                    # 默认知识库的向量库
│   │   └── chroma.sqlite3
│   ├── physics/                    # physics知识库的向量库
│   │   └── chroma.sqlite3
│   └── programming/                # programming知识库的向量库
│       └── chroma.sqlite3
```

## 映射关系

| 知识库ID | 原文件目录 | 向量库目录 |
|---------|-----------|-----------|
| default | data/default/ | vector_db/default/ |
| physics | data/physics/ | vector_db/physics/ |
| programming | data/programming/ | vector_db/programming/ |

## 迁移步骤

1. 重命名现有目录
2. 创建新结构
3. 更新配置文件
4. 修改API逻辑
