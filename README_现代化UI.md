## 📖 功能说明

### 💬 对话功能

**文本问答**
```
示例：什么是slab分配器？
```

**图片问答**
```
1. 上传图片（点击或拖拽）
2. 输入问题
3. 获得基于图片的回答
```

**文件问答**
```
支持：PDF, DOCX, PPTX, TXT, MD
自动OCR处理
```

### 📚 数据库管理

**切换数据库**
- 右侧栏选择目标数据库
- 点击"切换"按钮
- 状态栏显示切换结果

**创建数据库**
- 输入数据库名称
- 点击"创建"按钮
- 新库自动出现在列表中

**添加文件**
- 选择文件上传
- 设置课程标签
- 勾选是否使用OCR
- 点击"添加"完成

### 🎛️ 显示选项

**推理过程**
- 勾选后显示AI思考步骤
- 可折叠查看完整推理链

**Token统计**
- 勾选后显示API调用统计
- 监控成本和性能

## 🔧 技术栈

- **框架**: Gradio (主题自定义)

## 🐛 故障排除

### 启动失败
```bash
# 检查conda环境
conda activate rag

# 检查依赖
pip install gradio chromadb transformers torch
```

### 初始化失败
```bash
# 重建向量数据库
rm -rf vector_db image_vector_db
python process_data.py
```

### 页面样式异常
```
1. 清除浏览器缓存
2. 使用Chrome/Edge最新版
3. 刷新页面 (Ctrl + F5)
```
