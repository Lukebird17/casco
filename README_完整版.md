## 🚀 快速开始

### 1. 安装依赖

```bash
cd Proj2
pip install -r requirements.txt
```

### 2. 配置API

编辑 `config.py`:

```python
OPENAI_API_KEY = "your-api-key"
OPENAI_API_BASE = "https://api.deepseek.com"  # 或其他API端点
MODEL_NAME = "deepseek-chat"
```

### 3. 初始化知识库

**方式1：处理现有文件**
```bash
python process_data.py
```

**方式2：动态添加（推荐）**
```bash
# 通过Web界面的"数据库管理"标签添加文件
```

### 4. 启动系统

**完整增强版（推荐）**
```bash
python app_enhanced.py
```

**基础版**
```bash
python app.py
```

**命令行版**
```bash
python main.py
```

### 5. 访问界面

```
浏览器打开: http://localhost:7860
```

## 💡 使用技巧

### 1. 提高回答质量

- 使用清晰、具体的问题
- 提供足够的上下文
- 适当使用专业术语

### 2. 优化Token消耗

- 使用较小的top_k值（如3-5）
- 启用上下文优化
- 控制对话历史长度

### 3. 数据库管理

- 按课程分类组织文件
- 定期查看统计信息
- 使用OCR处理图片密集型文档

### 4. 多模态输入

- 确保图片清晰
- 图片文字大小适中
- 配合文字问题使用

## 🐛 常见问题

### Q1: 系统初始化失败？

**A:** 检查：
- API密钥是否正确
- 网络连接是否正常
- 向量数据库是否存在

### Q2: OCR识别不准确？

**A:** 尝试：
- 提高图片分辨率
- 确保文字清晰
- 切换OCR引擎（PaddleOCR ↔ Tesseract）

### Q3: Token消耗过高？

**A:** 优化：
- 减少top_k值
- 启用上下文压缩
- 缩短对话历史

### Q4: 数据库添加文件失败？

**A:** 检查：
- 文件路径是否正确
- 文件格式是否支持
- 是否有足够的磁盘空间
